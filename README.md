##  Overview

**NEXORA Intelligence** is an end-to-end **Business Intelligence & Predictive Analytics platform** that transforms raw sales and customer data into meaningful business intelligence, predictive insights, customer intelligence, and actionable recommendations.

The project combines **Data Science, SQL, Machine Learning, Business Intelligence, Customer Analytics, Predictive Analytics, AI-assisted Insights, and Web Application Development** into a unified analytics ecosystem.

NEXORA is designed to answer more than just:

> **"What happened?"**

It aims to help answer:

> **"What happened, what could happen next, and what business actions can be taken?"**

---

##  Project Vision

NEXORA Intelligence connects the complete journey from raw data to business decision support:

**Data → Analytics → Intelligence → Prediction → Action**

The project combines a production-style web application with a complete **Jupyter Notebook Data Science and Machine Learning workflow**, creating an end-to-end analytics solution.

###  RFM Customer Segmentation

NEXORA uses **RFM Analysis** to understand customer behavior.

| Metric | Meaning |
|---|---|
| Recency | How recently the customer purchased |
| Frequency | How frequently the customer purchased |
| Monetary | How much the customer spent |

Customer segments include:

-  VIP
-  Loyal
-  Potential Loyal
-  At Risk
-  Lost
-  Needs Attention

This enables differentiated customer strategies instead of treating every customer the same way.

#  Installation & Setup

## 1. Clone the Repository

    git clone https://github.com/rohanbhowm25308/nexora-ntelligence.git
    cd nexora-ntelligence

## 2. Create a Virtual Environment

### Windows

    python -m venv venv
    venv\Scripts\activate

### macOS / Linux

    python3 -m venv venv
    source venv/bin/activate

## 3. Install Dependencies

    pip install -r requirements.txt

## 4. Configure Environment Variables

Create a `.env` file based on `.env.example`.

    GROQ_API_KEY=your_api_key_here

Keep API credentials private and never commit the `.env` file to GitHub.

## 5. Run the Application

    python app.py

Then open:

    http://localhost:5000
